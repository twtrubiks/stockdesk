# 之後可能會做

跟使用者討論過、使用者說之後可能實作的想法。開工前先跟使用者確認。

## 社群文章抓回 App 內看（要 token）

現在社群只是在內建瀏覽器頁開討論區網頁。另一條路是直接打討論區的 API 把最新 N 篇文章與留言抓回來存著：
離線能看、能搜尋、能依讚／留言數排序，但每個請求要帶登入後的 token（會過期，要能自動換新）。
使用者說第一版不要 token，所以先不做。

## 行情、走勢、籌碼

另外三個資料來源（K 線與均線、當日分時走勢、籌碼日報／週報）。各有各的後端、握手與節流，行情那一套也要登入後的 token。
使用者說第一版不做，之後再討論。

## 拖曳排序

自選股現在是上移／下移一格。要拖曳的話 Compose 要自己寫 `LazyColumn` 的拖曳（或引入一個小套件）。

## 股票名稱表在 App 內更新

現在打包在 APK 裡，新股要發版才有。可以加「更新名稱表」按鈕從證交所、櫃買的公開端點抓（跟 `fetch_stock_names.py` 一樣的來源），存進資料庫蓋過打包的那份。

## App 內提醒更新

App 打開時（一天最多一次）查 GitHub 的 `releases/latest`，有新版就提示並給下載按鈕。不自己在背景下載安裝。

## 內建瀏覽器記住登入

GeckoView 的 cookie 存在它的設定檔（files/mozilla/），討論區登入一次之後下次打開應該還在；要是實測會掉再查。
